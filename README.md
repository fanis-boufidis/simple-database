This program is a simple student management system written in C that uses structures, arrays, and file handling to store and manage student information. It maintains a database of students in a text file named StudentsInformations.txt, where each student record includes an ID, name, entry year, and a logical deletion flag. When the program starts, it reads all existing student records from the file into an array. If the file is empty or does not exist, it creates the file and initializes it with a formatted header. The program then displays a menu that allows the user to add a new student, delete an existing student, search for a student by ID, or terminate the program. Adding a student involves entering the student’s personal details and either placing them in a new array position or reusing a previously deleted record. Deleting a student does not remove the record from memory or the file but instead marks it as deleted using a flag. Searching for a student checks whether the student exists and whether they are active or deleted, and reports the result accordingly. After every modification, the updated student list is written back to the file, ensuring data persistence between executions.
